# Rituais

O time trabalha **de forma assíncrona**: issues, PRs, comentários e documentos no repositório. A **weekly** é o único momento síncrono da dupla, então decisões e bloqueios que precisam de conversa vão para a pauta dela.

Atas de mentoria, weeklies e retros: um arquivo por encontro, `YYYY-MM-DD-type.md` (`mentoring`, `weekly`, `retro`).
