# Rituais

O time trabalha **de forma assíncrona**: issues, PRs, comentários e documentos no repositório. A **weekly** é o único momento síncrono da dupla, então decisões e bloqueios que precisam de conversa vão para a pauta dela. Conversas rápidas fora do GitHub acontecem em threads na DM do Slack, sem canais novos ([ADR-0012](../decisions/ADR-0012-async-communication-slack-threads.md)); o que for decidido lá vem para o repositório.

Atas de mentoria, weeklies e retros: um arquivo por encontro, `YYYY-MM-DD-type.md` (`mentoring`, `weekly`, `retro`).
