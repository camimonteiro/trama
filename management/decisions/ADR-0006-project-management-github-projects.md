# ADR-0006 — Gestão de tarefas no GitHub Projects

- **Status:** aceita
- **Data:** 2026-11-02
- **Pessoas envolvidas:** Camille Monteiro
- **Origem:** planejamento inicial

## Decisão
Tarefas como issues num quadro do **GitHub Projects** com colunas Backlog → In progress → In review → Done.

## Alternativas consideradas
Notion e Trello: descartados por ora para manter tarefas, código e PRs no mesmo lugar.

## Embasamento
- GitHub Projects: https://docs.github.com/issues/planning-and-tracking-with-projects/learning-about-projects/about-projects
