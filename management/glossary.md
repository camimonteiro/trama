# Glossário

| Termo | Significado |
|---|---|
| ADR | Architecture/technical Decision Record — registro de decisão técnica |
| DDR | Design Decision Record — registro de decisão de design |
| OQ | Open Question — questão aberta em `open-questions.md` |
| Branch | Linha paralela de trabalho que não afeta a `main` até o merge |
| Commit | Um "salvamento" com descrição no histórico do git |
| PR (Pull Request) | Pedido para juntar uma branch à `main`, com review |
| Squash merge | Junta todos os commits do PR em um só na `main` |
| Ruleset | Regra do GitHub que protege uma branch (ex.: exige aprovação) |
| GitHub Actions | Automação que roda a cada evento (ex.: publicar o site) |
| GitHub Pages | Hospedagem estática do GitHub, onde o hub fica publicado |
| Agente de AI | Ferramenta de AI que lê e altera o repositório (Claude Code, Codex, Cursor…) |
| AGENTS.md | Arquivo de instruções lido por agentes de AI |
| Skill | Procedimento reutilizável para agentes, num `SKILL.md` |
| [Claude-only] | Marca de algo que só funciona no Claude Code |
